# Customer Shopping Behavior Analysis

## Overview
Analyzed customer shopping behavior using transactional retail data to uncover insights related to customer spending, subscriptions, discounts, and product preferences.

## Tech Stack
- Python (Pandas, NumPy)
- PostgreSQL
- Power BI

## Dataset
- 3,900 customer purchase records
- 18 features
- Includes demographics, purchase history, ratings, shipping, discounts, and subscriptions

## Data Preprocessing
- Handled missing values
- Standardized column names
- Performed feature engineering
- Removed redundant columns
- Loaded cleaned data into PostgreSQL

## SQL Analysis
Performed business analysis including:
- Revenue by gender
- Subscriber vs non-subscriber spending
- High-spending discount users
- Top-rated products
- Customer segmentation
- Revenue by age group
- Shipping preference analysis

## Power BI Dashboard
Created an interactive dashboard to visualize:
- Revenue trends
- Customer segments
- Product performance
- Subscription insights
- Discount impact

## Key Insights
- Loyal customers contribute significantly to revenue
- Subscribers tend to spend more
- Certain products heavily depend on discounts
- Express shipping users show higher purchase values

## Future Improvements
- Customer churn prediction
- Recommendation system
- Sales forecasting
- Real-time analytics pipeline

## Conclusion
This project demonstrates end-to-end data analysis using Python, SQL, and Power BI to generate actionable business insights from retail customer data.
